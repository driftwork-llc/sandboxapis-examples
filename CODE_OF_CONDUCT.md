# Code of conduct

This repository follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be straightforward, assume the other person is trying to help, and keep
the conversation about the code and the data. Harassment of any kind is not
welcome here and will get an account blocked from the repository.

Report anything that needs reporting to team@sandboxapis.dev. Reports are read by
the SandboxAPIs team and are not shared further.
